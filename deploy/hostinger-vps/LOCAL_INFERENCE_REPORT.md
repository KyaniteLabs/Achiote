## Key Findings

### 1. MoE (35b-a3b) is the winner ✅
The 35B MoE model activates only ~3.5B parameters per forward pass, making it **faster than the dense 9B** while producing much better tool-calling quality. It completed the full 3-step workflow with **zero retries** — the most reliable model tested.

**Use this if the model is loaded:**
```env
ACHIOTE_ASK_MODEL=qwen3.6-35b-a3b
```

### 2. Server contention is real — patience required
The NUC Box runs 7 models simultaneously. Under load:
- Dense models (27b, 9b, 4b) may timeout on first attempt
- Always implement retry logic with exponential backoff
- A warmup call (no tools) improves subsequent tool-call reliability
- **Wait 10s between models** to avoid compounding server load

### 3. LFM 1.2b skips the cue step ⚠️
Reliably calls `collect_food_memory` and `plan_dish_research`, then stops without calling `generate_minimum_viable_nostalgia`. The existing `missing_research_plan_clarification` guard should handle this.

## Server Etiquette

This server serves multiple users. Be a good neighbor:

1. **Wait 10s+ between model switches**
2. **Use warmup calls** (simple query, no tools) before complex workflows
3. **Implement retry with backoff** — don't hammer on first timeout
4. **Avoid peak hours** if possible (evenings in user's timezone)
5. **Set reasonable timeouts** — 60-120s for local inference, not infinite
