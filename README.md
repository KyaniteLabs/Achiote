# Achiote

MCP server for research-first food-and-drink memory reconstruction. Give it a fragment of a remembered dish, drink, name, place, smell, or ritual; it structures clues, plans evidence-led research, and separates facts from inference.

**Who it is for:** people chasing diaspora / family food memories with honest research — not recipe spam or fake certainty.

**What you get:** an MCP tool surface for food-memory reconstruction (build from source; not claimed as a published npm install in this face).

## Try it

```bash
git clone https://github.com/KyaniteLabs/Achiote.git
cd Achiote
# build the MCP stdio server from the package scripts in-tree
npm install
npm run build
```
