Achiote / Roadmap

Roadmap

Achiote’s roadmap stays centered on trustworthy reconstruction: richer reference data, better local-first inference, shareable evidence receipts, and launch-grade reliability.

Now

Dense reference data

Broaden and deepen coverage across dishes, drinks, techniques, mechanisms, regions, ingredient families, and sourcing cues so the app relies less on emergency search.

Now

Shareable Memory Receipts

Make family-safe receipt sharing possible without exposing private prompts to the server by using a possession-based receipt link.

Next

Local speech and multilingual memory capture

Improve speech-to-text, accents, code-switching, and family-language capture for people who remember food orally first.

Next

Research provenance and DOI validation

Strengthen source validation, citation hygiene, and external DOI validation for food-science claims and reference records.
