## Executive Summary

The current Achiote landing page (`achiote.kyanitelabs.tech`) has solid bones but misses critical 2026 marketing opportunities:

1. **No AI Engine Optimization (AEO)** — The page isn't structured for LLM citation (ChatGPT, Perplexity, Claude, etc.)
2. **Weak hero clarity** — Visitors don't know if this is for developers, food lovers, or AI researchers in under 3 seconds
3. **Missed semantic SEO** — The global names of Achiote (the spice) are a massive untapped keyword cluster
4. **Weak CTAs** — "Install" before value is established; older demo framing undermines credibility

## The Big Idea: The Global Names of Achiote

**User's concept:** Showcase every name Achiote is known by worldwide, displayed like a living manuscript — names transforming across scripts, languages, and cultures.

**Why this is brilliant for SEO/AEO:**
- Captures **long-tail search volume** for every regional name ("urucum," "roucou," "atsuete," "beninoki")
- Creates **topical authority** — Google/AI engines see deep semantic coverage
- Builds **emotional resonance** — food memory is inherently cross-cultural
- **Natural keyword clustering** — each name is a searchable term that leads back to Achiote
- **Featured snippet potential** — "What are other names for achiote?" is a high-volume query

## Proposed New Section: "One Seed, a Hundred Names"

**Placement:** Immediately after the hero, before the problem section.

**Purpose:**
- SEO/AEO: Massive keyword coverage
- Emotional hook: Food memory is universal — you might know it by a different name
- Brand story: The name itself embodies the project's mission (reconstructing fragmented memories)
- Conversion: If someone searches "urucum" or "atsuete" and lands here, they immediately understand the connection

**Visual concept:** A flowing horizontal scroll or grid of name cards, each showing:
- The name in its native script
- The romanization
- A small flag or region indicator
- A subtle hover effect that reveals the meaning

**Copy for the section header:**

> **You might know it by another name.**
> 
> Achiote is annatto. It's urucum, roucou, atsuete, achiotl, bija, onoto, kesumba, latkan, beninoki — a single seed called a hundred names across every continent it touched. The name changes. The memory doesn't. That's why this project exists.

## New Section: "What Is Achiote?" (AEO-Optimized)

**Placement:** Before the footer, or as an expandable FAQ.

**Format:** H2 heading + 6 concise Q&A blocks. Each answer is 40–60 words — the sweet spot for LLM citation.

**Sample Q&A:**

> **What is Achiote?**
> Achiote is a source-available Model Context Protocol (MCP) server that helps AI agents reconstruct nostalgic dishes and drinks from fragmented food memories. It provides 15 deterministic tools for memory collection, research planning, provenance tracking, sensory analysis, and generating minimum viable nostalgia cues.

> **How does food memory reconstruction work?**
> Achiote follows a 5-step workflow: collect the memory fragment, plan research hypotheses, build an evidence-separated dossier, generate the smallest sensory cue to test, and help source ingredients. Your AI does the live research; Achiote keeps it structured, honest, and organized.

> **What is a minimum viable nostalgia cue?**
> The smallest practical aroma, bite, sip, or condiment that tests whether a reconstructed memory is on the right track. It uses grocery-store ingredients and takes under 15 minutes — before anyone commits to a full recipe or shops for specialty items.

> **What are other names for achiote?**
> Achiote is known as annatto (English), urucum (Portuguese/Brazil), roucou (French/Caribbean), atsuete (Tagalog/Filippines), bija (Carib/Andes), onoto (Venezuela), kesumba (Indonesian), beninoki (Japanese), latkan (Hindi), and achiotl (Nahuatl) — among dozens of others across every continent.

> **Can I use Achiote with ChatGPT or Claude?**
> Yes. Achiote runs as an MCP server. Add it to Claude Code via `.mcp.json`, to OpenAI Codex via `config.toml`, or to any agent that supports the Model Context Protocol. Hosted API and MCP production access require a commercial license.

> **Is Achiote free?**
> Achiote is source-available under the Business Source License 1.1. The hosted app includes 3 guided memories per month. Hosted API and MCP access require a commercial license. Self-hosting is available for non-production use under the BSL; production self-hosting requires following the BSL terms or a commercial license.
