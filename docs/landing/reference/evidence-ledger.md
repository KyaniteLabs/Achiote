# Evidence Ledger

The evidence ledger is the main anti-slop device. Use it whenever the answer makes a claim about a dish, drink, ingredient, region, technique, or local source.

## Ledger fields

```text
User said:
- Claims directly supplied by the user.

Researched:
- Claims found in external sources.
- Include source type and confidence.

Inferred:
- Reasoned links from user clues, food science, or source patterns.
- Must be labeled as inference.

Unknown:
- Facts that remain unresolved.

Would change my mind:
- The specific clue, source, or family answer that would alter the hypothesis.
```

## Evidence rules

1. A user memory is evidence of memory, not proof of dish identity.
2. A recipe blog is evidence of a possible preparation, not proof that the user's family made it that way.
3. A bilingual/community source may be stronger for naming and lived context than a generic SEO recipe.
4. A grocery page can support availability only at the time checked.
5. A food-science mechanism can justify a cue even when exact identity is unknown.
6. An inference must stay labeled until confirmed.

## Short ledger template

```text
Evidence ledger
- User said:
  - ...
- Researched:
  - ...
- Inferred:
  - ...
- Unknown:
  - ...
- Would change my mind:
  - ...
```

## Confidence labels

Use plain labels:

- High: multiple strong clues and good sources align.
- Medium: plausible but one or two important facts remain unresolved.
- Low: useful direction, not an identification.
- Unknown: no identity claim; work from sensory mechanism only.

Never use confidence as decoration. Explain why.
