Week 6 · The Researcher

The folder is the researcher.

Achiote is a model-agnostic folder for food-memory reconstruction. Drop it into any model workspace and it plans, researches, reasons, and returns a Memory Receipt, with local sourcing, language clues, and evidence boundaries intact.

The system

Inside the folder

Each file does one job. Together they teach any frontier model to investigate before it answers, and to keep the evidence honest.
