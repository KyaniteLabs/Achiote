Entry Points
bin/achiote.mjs
CLI binary. Launches MCP server over stdio for Claude Desktop, Cursor, etc.
src/http-server.ts port 3000
Standalone HTTP server. SSE chat endpoint, MCP transport, static files, auth, rate limiting.
src/cli.ts
Stdio MCP server with graceful shutdown. Used by the bin entry point.
Server Layer
POST /ask SSE stream
Chat endpoint. Anthropic SDK drives Claude through a 5-step tool-use loop (max 15 iterations). Streams text events to the client.
Auth: auth.ts · Rate limit: rate-limit.ts · CORS + CSP
POST /mcp Streamable HTTP
MCP protocol endpoint. Session-based transport via mcp-session-id. Exposes all 14 tools for remote MCP clients.
Transport: StreamableHTTPServerTransport · Server: src/server.ts
GET /health
Returns status, version, auth state, active sessions.
Static Files
Serves docs/landing/ — routes / to app.html, /about to index.html.
Auth + Rate Limiting
ach_ prefixed keys. Timing-safe comparison. Tier-based monthly quotas (free: 3 web / 50 MCP).

Library Modules — src/lib/
memory-workflow.ts
955 lines. Regex-based extraction, hypothesis generation, dossier building, MVN cue creation.
name-resolver.ts
Levenshtein distance + transliteration matching. Ambiguity detection.
substitution-engine.ts
Jaccard similarity on volatile compounds. Substitution group bonus. High/Medium/Low confidence.
regional-matcher.ts
Location string to region key lookup against availability data.
research-provenance.ts
Build, validate, extract findings from typed research records.
research-cache.ts
SQLite (WAL) cache keyed by (dish_family, region). 512KB max entries.
auth.ts
ach_ key gen, timing-safe auth, tier validation, 4 tiers.
rate-limit.ts
Per-key, per-tier monthly quota tracking. Calendar-month reset.
types.ts
~277 lines of shared interfaces. SensoryProfile, Dossier, ResearchRecord, etc.
data-schemas.ts
Structural validation for all bundled JSON data files.
cache-path.ts
Cache path resolution. XDG or env override.
schemas/ + tools/
Zod schemas for all 14 tools. Result helpers: structured JSON, sanitization, errors.
Bundled Data — src/data/
dish-families.json 40 families
Canonical names, aliases, transliterations (Arabic, Turkish, Greek...), regions (5+), shared/divergent elements, nostalgia triggers, variants.
ingredients.json 82 ingredients
Keyed by slug. Volatile compounds, sensory contribution, substitution groups, cultural regions, aliases (3+), DOI-cited science.
regional-availability.json
US regional sourcing. Ethnic corridors, major stores, cuisine categories per metro area.
sensory-profiles.json
5 dimensions (aroma, texture, flavor, visual, temperature) with scales, categories, nostalgia indicators. Cites Reid 2023, Yamamoto 2025.
food-science-references.json
Mechanism areas (fat-soluble aromatics, Maillard browning, etc.) with summaries, practical implications, and DOI-linked sources.
